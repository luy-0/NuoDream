## 带着一个困惑，入梦

你来到山门前，留下名字，以及一件此刻看不清的事。

“傩”不会替你预测未来，也不会立刻给出答案。它从你的困惑中辨认出犹疑、失去、责任、恐惧或渴望，请出一位与之相照的职司，再带你进入一场以贵州傩文化角色和地方叙事为母体创作的先民故事。

你会跟随故事走过他们曾经面对的窄路：明知可能失败，是否仍要开始；事情已经结束，是否还要背负余响；答案尚未出现，是否仍愿意生活。幻梦结束时，你得到一张傩面、一项职司与一份有所指向的傩解——它们不定义你是谁，只回应面对眼前之事，你可以暂时成为什么。

## 为什么是先民的困境

古人与今人面对的现实并不相同，但迷雾有时拥有相似的形状。失去、犹疑、责任、关系、未知和重新开始，并不只属于某一个时代。

《大傩幻梦》尝试让玩家暂时离开自己的问题，进入另一个人的处境。借由时间与故事制造的距离，那些纠缠在一起的情绪开始显露轮廓；玩家不是从先民那里领取标准答案，而是在经历他们的困境之后，重新辨认自己的道路。

> 幻梦不替人驱散所有迷雾。它只是点起一盏灯，让人看清下一步落在哪里。

## 一场完整的幻梦

| 阶段 | 你会经历什么 | 留下什么 |
| --- | --- | --- |
| **入戏** | 走过山门，在龙坛留下名字与现实困惑，由八大职司中请出一张相照的面 | 一条进入故事的线索 |
| **幻梦** | 进入一段固定的五至七幕叙事，经历先民在另一种时代处境中的选择与挣扎 | 一次与自身困境保持距离的观看 |
| **得面** | 故事结束后揭示傩面、职司、傩签、傩解与文化溯源 | 一种面对眼前之事的临时身份 |
| **归谱** | 将所得之面收入本机傩谱，查看面具细节、角色来历与相关图录 | 一份可以重访的个人记录 |

## 八场幻梦，八种迷雾

当前原型收录了八位职司及其对应故事。每场幻梦从一种具体困境出发，而不是为同一套结果更换外观。

| 职司 | 幻梦 | 故事面对的困境 |
| --- | --- | --- |
| 开路将军 | 《渡山记》 | 明知可能失败，是否仍要开始 |
| 先锋小姐 | 《一梭花》 | 条件不齐时，是等待还是先上手 |
| 九位土地神 | 《第九坛》 | 众事缠身时，究竟先抓住什么 |
| 唐氏太婆 | 《归正记》 | 别人的说法，是否是衡量自己的尺子 |
| 勾簿判官 | 《合页记》 | 众多真实身份之间，是否必须舍弃一个 |
| 扫地和尚 | 《余火记》 | 停止受苦，是否等于逃避责任 |
| 柳毅 | 《一信渡水》 | 开口求助，是否等于丢脸 |
| 阿布摩 | 《荒年开火》 | 没有想明白，是否就没有资格继续生活 |

## AI 在这里做什么

在当前运行版本中，AI 不扮演故事作者或神谕。玩家进入的幻梦由预先创作、校验并固定下来的内容构成，选定后不会由模型临场改写；故事匹配首先由本地确定性规则完成，外部模型只用于可选的傩签与傩解生成。

这样的边界是有意为之：如果每一次体验都只是即时生成的神秘文本，先民的困境、角色的职司与最后所得之面便无法彼此解释。《大傩幻梦》希望 AI 帮助玩家找到一场与自身相照的故事，而不是用随机性代替故事。

## 文化与创作边界

《大傩幻梦》借鉴贵州傩堂戏、傩面具、撮泰吉等文化材料中的角色、仪式结构和职能意象，但它不是传统傩仪的数字复刻。项目中的幻梦剧情、互动机制、部分职司与签解属于当代创作，不应被理解为历史事实、民俗定论或真实仪式。

- 传统角色借鉴与项目新创角色在数据中分别标记，并尽可能保留来源说明。
- 项目不宣称傩仪可以改变现实，也不提供占卜、诊断、治疗或其他专业建议。
- 当前面具图像是项目运行素材，不是文物扫描；历史身份或授权不明确的素材会明确提示。
- 愿望只用于完成当前体验；本机傩谱不保存愿望、人像、视频帧或服务端配置。

文化资料、来源索引与研究边界见 [贵州傩文化与非遗参考材料](./reference-materials/贵州国文化与非遗参考材料.md)。

## 本地运行

项目使用 Next.js App Router，要求 Node.js `24.x`。

```bash
git clone git@github.com:luy-0/NuoDream.git
cd NuoDream
npm ci
npm run dev
```

打开 <http://localhost:3000>，从山门开始体验。生产构建可运行：

```bash
npm run build
npm run start
```

如果没有配置外部 AI provider，核心故事体验仍可运行；需要模型生成的傩签接口会明确返回未配置状态，而不会在浏览器中暴露密钥。
